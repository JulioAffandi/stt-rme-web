# Frontend — Klinik Demo (RME STT-NLP)

Frontend React + Vite untuk demo RME. Pandangan lengkap (cara menjalankan, arsitektur, kredensial demo):
**lihat [README utama di root repository](../README.md)**.

Perintah singkat:

```bash
npm install
npm run dev      # http://localhost:5173 (proxy /api -> backend :8000)
npm run build    # typecheck + bundling produksi
npm run lint     # oxlint
npm run format   # prettier
```
